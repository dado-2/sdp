# Systematic Literature Review on AI in Software Defect Prediction

## Overview
This repository contains a systematic literature review on the application of Artificial Intelligence (AI) in Software Defect Prediction (SDP). It includes various machine learning and deep learning techniques, datasets, and future research directions.

## Contents
- **data/**: Contains datasets for software defect prediction.
- **src/**: Source code for implementing defect prediction models.
- **notebooks/**: Jupyter notebooks for model demonstrations.
- **requirements.txt**: List of required Python packages.

## Datasets
Recommended datasets for software defect prediction include:
- NASA MDP Datasets
- PROMISE Repository Datasets
- Defects4J
- Bugzilla Datasets
